# Pooja Patil — Full-Stack Developer Portfolio

## Quick start

This is a static, responsive portfolio. No framework or build step is required.

1. Open `index.html` in a browser.
2. Replace the placeholders for email, LinkedIn and GitHub.
3. Put your CV in the folder as `resume.pdf`.
4. Replace Project 02 and Project 03 with your real projects.
5. Update the About/Experience text with your actual professional experience.

## Publish for free

You can deploy this folder using GitHub Pages, Netlify, Vercel, or another static hosting provider.
